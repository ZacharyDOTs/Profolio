# Zachary Yang 作品集

純靜態網站，部署在 GitHub Pages。新增作品只要放資料夾、推上 GitHub，網頁會自動更新。

## 放作品

每個案子一個資料夾，放進 `projects/`。資料夾命名：

```
[排序數字-]標題__類別
```

```
projects/
├─ 01-台北馬拉松__運動賽事/        ← 數字最小的「平面」= 左側直式主打
│    ├─ 001.jpg
│    ├─ 002.jpg                    ← 平面：照片全部自動歸進這張卡片，第一張當封面
│    └─ ...
├─ 01-品牌形象片__影片製作/        ← 數字最小的「動態」= 右側大橫幅主打
   （上面兩個編號都是 01 沒關係，平面與動態各自比較）
├─ 02-另一個案子__類別/
│    ├─ final.mp4                  ← 動態：取第一支影片，封面 = 影片第一個畫面，點一下直接播放
│    └─ youtube.txt                ← 選填：第一行貼 YouTube 連結，卡片上會出現「YouTube ↗」
└─ _草稿__測試/                    ← 開頭是 _ 或 . 的資料夾不會顯示
```

- 一個案子只放照片或只放影片。同時有影片與圖片時，只會當成影片。
- 主打區固定是：左邊一張直式的平面作品、右邊一支橫式的動態作品，高度自動對齊；只有其中一種時，就只顯示那一個大卡片。
- 其餘作品大小一致；直式影片或照片放在這些卡片裡會完整顯示、兩側留黑邊。
- 檔名避免使用 `#` 和 `?`。

## 檔案大小建議

- 影片：壓成 H.264 mp4，每支盡量 10–30MB。單檔不能超過 100MB，整個網站建議 1GB 以內。
- 照片：先縮到長邊約 2000px、每張 300–600KB，網頁讀取才快（封面直接使用第一張原圖）。

## 第一次部署

1. 在 GitHub 建立新 repo，把這個資料夾的所有檔案（包含隱藏的 `.github` 資料夾）推上去，分支用 `main`。
2. repo 的 Settings → Pages → Build and deployment → Source 選 **GitHub Actions**。
3. 推上去之後等 Actions 跑完（約 1 分鐘），網址會是 `https://<帳號>.github.io/<repo 名稱>/`。
4. 之後每次新增資料夾並推上去，就會自動重新掃描並部署。

照片很多時，網頁拖拉上傳一次有 100 個檔案的限制，建議用 GitHub Desktop 或 git 推送。

## 本機預覽

```
python build.py
python -m http.server 8000
```

瀏覽器開 http://localhost:8000 。不要直接點開 index.html，瀏覽器會擋讀取檔案。

## 檔案說明

- `index.html` `style.css` `app.js`：網頁本體
- `build.py`：掃描 `projects/` 產生 `projects.json`
- `.github/workflows/deploy.yml`：自動掃描並部署到 GitHub Pages
